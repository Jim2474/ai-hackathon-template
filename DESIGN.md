# Claudio Design Direction

## Core Direction

Claudio is a private AI radio player. The visual system should feel like a small personal music device floating above a soft wall of album covers.

The locked direction is:

- Centered phone radio shell.
- Blurred album-cover collage background.
- Strong liquid glass surfaces with obvious refraction, edge highlights, and chromatic color shift.
- Brand name must stay `Claudio`.
- Never return to a dark gradient stage, a white Apple page, or a desktop dashboard as the main screen.

## Background

Use a collage of album covers whenever track artwork is available. If live covers are unavailable, use built-in music-color tiles as placeholders.

The album wall should be:

- Highly blurred.
- Slightly desaturated.
- Medium brightness.
- Low contrast.
- Supportive of the foreground glass, never competing with chat or player text.

## Phone Shell

The first viewport should always show the phone-style radio surface:

- Header with Claudio identity and status.
- Chat/radio message stream.
- NetEase library entry inside the phone.
- Fixed lower player area inside the phone.
- Input row and quick mood chips.

Avoid split-screen layouts for the main experience.

## Liquid Glass

Glass must remain visually strong:

- High displacement/refraction.
- Saturated color passing through from album art.
- Bright top edge and subtle side color fringing.
- Settings sliders must produce visible changes.

Glass is the signature effect; do not flatten it into ordinary translucent cards.

## Voice

Claudio speaks like a radio DJ, not a report generator.

Song Story should be short, varied, and tied to the current track, artist, source, and user moment. Avoid repeating one fixed sentence across every song.
