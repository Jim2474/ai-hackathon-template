# Moodwave - AI 情境音乐播放器

一个能根据你的状态、情绪、目标和时间，自动生成音乐场景方案的 AI 音乐规划师。

## 功能特点

- 🎵 **智能规划**：告诉 AI 你现在的状态，自动生成音乐方案
- ✨ **粒子视觉**：全屏粒子效果，根据状态变化视觉效果
- 🎨 **暗系 UI**：高级、克制、干净的暗色系界面
- 📱 **简单易用**：输入文字或点击快速按钮即可使用

## 技术栈

- React 19 + Vite
- Tailwind CSS
- p5.js（粒子效果）
- Mock 数据（无需后端）

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:5173/

## 使用说明

1. 在输入框中描述你现在的状态，比如：
   - 「我现在很困，但还要学 2 小时高数」
   - 「我想睡前放松，30 分钟后自动停止」
   - 「我现在有点焦虑，想安静下来」

2. 或点击下方的快速按钮（学习、睡觉、运动、安抚）

3. 等待 AI 规划方案

4. 点击「开始播放」

## 预设模式

- 📚 专注模式 - 学习/工作
- 😴 睡眠模式 - 睡前放松
- 🧘 安抚模式 - 缓解焦虑
- 🏃 运动模式 - 运动健身
- 🎧 白噪音模式 - 背景噪音

## 粒子效果说明

- **空闲时**：粒子缓慢漂浮
- **思考中**：粒子向中心聚合
- **播放中**：根据模式变化
  - 专注模式：粒子稳定环形轨道
  - 睡眠模式：粒子慢速漂浮
  - 安抚模式：粒子从混乱到平稳
  - 运动模式：粒子脉冲扩张
